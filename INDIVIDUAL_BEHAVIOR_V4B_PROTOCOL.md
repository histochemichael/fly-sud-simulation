# V4b: explicitly labeled follow-up calibration

V4 is completed and failed its gate. Gains 5 and 20 gave positive early CPI; gain 80 gave negative early CPI but saturated late preference. Those outcomes inform this new development step.

Test a single intermediate absolute-value gain of 50. All other controller and variability distributions remain unchanged. Use calibration seed 410724, 4 reciprocal pairs per delay, 16 individual flies per delay, 32 flies total. Apply the same gate prospectively; do not select a replacement if it fails.

Only after passing: freeze gain 50 and run 256 validation flies with independent seed 920618, 8 reciprocal pairs per condition/delay, all four conditions. Preserve the same V4 declared effect, response, statistical and audit criteria.

This is one bounded follow-up, not an open-ended search. Timing points remain calibration data; seed independence does not make them held-out biological time points. Original V4 and V3 runs remain unchanged. See the V4 protocol for equations, provenance and limitations.
